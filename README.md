# 无线干扰小区周报全自动采集与分析系统

基于 FastAPI + 现代 Web 响应式界面，整合大数据平台即席查询（NQI JXCX）采集算法与融合周报算法的一体化平台。

## 主要功能

1. **统一身份安全认证与状态管理**
   - 完美适配大数据平台 CAS 登录体系，支持公钥 RSA 加密与图形验证码、短信验证码安全交互。
   - 支持 Cookie/CASTGC 智能复用与会话自动保活，避免重复登录。

2. **多线程全省 21 地市干扰数据自动采集**
   - 支持自定义选择起止周区间（默认最近 7 天）及 4G/5G 制式。
   - 自动规划（21 地市 × 日期 × 制式）任务阵列，内置线程池并发高效拉取。
   - 智能断点与本地源数据缓存，避免网络重复拉取。

3. **融合算法智能分析与周报输出**
   - 严格遵循《干扰小区周报_脚本_融合版》规范，输出融合版 Excel：
     - **Sheet1（干扰电平判断）**：按干扰门限（4G > -105dBm，5G-700M > -105dBm，5G非700M > -107dBm，7天 >= 3天）统计。
     - **Sheet2（干扰小区标识判断）**：按源文件【是否干扰小区】标识字段统计。
   - 自动生成：
     - 阳江 4G/5G 明细表（区域、CGI、频段、门限、干扰天数、每日干扰电平）；
     - 阳江 4G/5G 汇总块（总小区数、本周干扰数、占比、全省排名、三类排名）；
     - 阳江区域与频段交叉分布统计表（江城、阳东、阳西、阳春、南区）；
     - 全省 21 地市三类排名（一类/二类/三类）汇总表。

4. **Web 实时交互与报表中心**
   - 实时进度条与彩色流式控制台日志。
   - 生成后一键直达下载，支持历史生成报表管理。

## 启动方式

```bash
python3 run.py
```
启动后在浏览器打开：`http://127.0.0.1:8090` 即可使用。
